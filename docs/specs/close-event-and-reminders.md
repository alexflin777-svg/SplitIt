## A. Закрыть событие → итог
**Сценарий.** Организатор нажимает «Подвести итог». Показывается предпросмотр: итоговый баланс, минимальный список переводов (debt-simplification) и предупреждение «после закрытия расходы менять нельзя». После подтверждения:
1. `groups.status='completed'`, `completed_at`, `completed_by`. Итоговые переводы сохраняются в `group_settlement_plan` (снимок, чтобы итог не «плыл» от курса валют).
2. Каждому участнику показывается карточка «Вы должны X → Имя» / «Вам должны». Кнопки «Отметить оплаченным» (подтверждает получатель) и «Поделиться итогом» (картинка + ссылка в любой мессенджер).
3. Когда все переводы подтверждены, статус меняется на `settled`, в ленте появляется бейдж «Рассчитались ✓».
4. Переоткрыть событие может только владелец, с записью в историю.

**Защита на уровне БД (обязательно):** RLS/триггер запрещает INSERT/UPDATE/DELETE в `expenses` и `expense_splits`, если группа не `active`. UI — только вторая линия защиты.

**Приёмка:**
- Unit: сумма переводов = сумме долгов, нет отрицательных, NaN и Infinity.
- RLS-тест: после закрытия прямая вставка расхода от участника отклоняется.
- E2E: 2 пользователя, закрыть событие → оба видят одинаковый итог → подтвердить оплату → `settled`.
- Скриншоты 375×812 и desktop.

## B. Напоминания о долгах
Три уровня, в порядке внедрения:
1. **Сразу, без инфраструктуры:** кнопка «Напомнить» → системный share-sheet с готовым текстом и ссылкой на итог (Telegram, WhatsApp, SMS). Работает в web, Android и iOS.
2. **Email-напоминания** (нужен SMTP из плана безопасности). Supabase cron (`pg_cron`) + Edge Function: через 3 и 7 дней после закрытия, если долг не подтверждён. Не чаще одного письма в 3 дня, ссылка «отписаться».
3. **Push:**
   - Firebase-проект → `android/app/google-services.json` (в .gitignore не кладём: файл не секретный, но хранится в `~/secure` и подставляется в CI);
   - APNs-ключ (.p8) в Firebase для iOS;
   - таблица `push_tokens(user_id, token, platform, updated_at)` с RLS «только свои»;
   - Edge Function `send-reminders` (FCM HTTP v1, service account в Supabase secrets);
   - триггеры отправки: новый расход в моей группе, событие закрыто, мне напомнили, долг подтверждён;
   - настройки в профиле: включить/выключить по типам; экран запроса разрешения с объяснением (Android 13+ и iOS).
4. **Telegram-бот** (опционально): если вошёл через Telegram — напоминание от @splititapps_bot.

**Приёмка:** на реальном Android и iPhone приходит push «Напоминание: вы должны X» и по тапу открывается нужное событие; отключение в профиле работает; rate limit — не больше 1 напоминания одному человеку по одному долгу в сутки.
