# Product Requirements Document (PRD) — SplitIt (Сплит-Чек)

## 1. Обзор продукта
**SplitIt** — современное веб-приложение для разделения совместных расходов, отслеживания долгов и автоматического расчета взаиморасчетов в группах (поездки, мероприятия, совместная аренда, рестораны).

Продукт разрабатывается на основе макетов и дизайн-системы из **Google Stitch** (Проект: `Сплит-Чек: Совместные расходы`).

---

## 2. Архитектура и Технологический Стек
- **Frontend**: Next.js 14+ (App Router, TypeScript, Tailwind CSS, Shadcn UI, Lucide Icons, Canvas-Confetti, Framer Motion).
- **Backend & Database**: Supabase (PostgreSQL, Auth, Storage, Edge Functions / SQL Migrations).
- **Аутентификация**: Supabase Auth (Email / Пароль + Magic Link) с готовыми хэндлерами для Telegram WebApp integration.
- **Мультивалютивность**: Поддержка мультивалютных расходов (RUB, USD, EUR, KZT, GEL) с автоматической и ручной конвертацией валют.
- **Алгоритм упрощения долгов (Debt Simplification)**: Алгоритм минимального количества платежей в графе должников.
- **Интеграция чеков**: Опциональное прикрепление фото чеков + встроенное OCR-распознавание наименований и сумм (Tesseract / Vision API integration).
- **Миграции БД**: Строго через SQL-миграции в Supabase (`supabase/migrations`).
- **Дизайн-система**:
  - Основной цвет (Primary Blue): `#3b82f6`
  - Успех / Возврат долга (Success Green): `#10b981`
  - Ожидание / Долг (Warning Orange): `#f59e0b`
  - Нейтральный (Neutral Slate): `#64748b`
  - Фоны (Surface/Background): `#f8f9ff` (светлая тема), `#131313` (темная тема)
  - Типографика: Inter

## 3. Картография экранов и пользовательские сценарии (Stitch UI)

### 3.1. Модуль авторизации и профиля
- **Аутентификация**: Форма входа/регистрации по E-mail / Паролю, отсыпка Magic Link и авто-авторизация в Telegram WebApp.
- **Профиль пользователя**: Редактирование аватарки, имени, основного счета/телефона (`dd1993a85e3e4c3eac5f65b361724212`).
- **Настройки уведомлений**: Переключение системных уведомлений по группам, темная/светлая тема (`d7e5d278346f4d4aba7b15f137b61bc2`).

### 3.2. Управление событиями и группами
- **Список событий**: Обзор всех активных и завершенных поездок/групп с суммами баланса пользователя (`1f77ed008f4344298b70bc977329a3b0`).
- **Создание события**: Ввод названия, категории (Поездка, Ресторан, Дом, Вечеринка), выбор базовой валюты события и участников (`c124614331de4e57bde06fd11d4c4c7b`).
- **Детали события**: Лента расходов группы, текущие балансы участников, динамика расходов (`0bcd06ae324d46ac8476c5a736939665`).

### 3.3. Расходы и транзакции (Мультивалютность + OCR)
- **Добавление расхода**: Выбор кто платил, суммы, валюты платежа (с конвертацией), категории, загрузка чека и встроенное OCR-распознавание текста/суммы (`fcabaf3775024441a60d3261bc475939`).
- **Схемы сплита**: Поровну, по точным суммам, по долям/процентам.
- **Детали и редактирование транзакции**: Просмотр полного состава чека, участников и истории изменений (`9dccb91ac80a4dfa96d66cea493e246c`, `4b28aaf8ecdb488c9d882b82b1c7ae2d`).

### 3.4. Балансы, Оптимизация долгов и Оплата
- **Итоговый расчет & Граф долгов**: Сводная ведомость с применением алгоритма транзитивного сокращения долгов (Debt Simplification) для сведения транзакций к минимуму (`735b8bbfcb5b45549dc3bee035c9a8c8`, `808f1b0319f44433ac27f58ae159ecb6`).
- **Фиксация оплаты (Settle Up)**: Ввод перевода между участниками, выбор способа (СБП, Карта, Наличные), загрузка подтверждения (`e25b894b06ed4ef395874f8161b3af69`).
- **История долгов**: Полный лог всех взаиморасчетов и платежей с фильтрацией (`68c1cac747264f29ab424e0369b738a1`).

### 3.5. Социальные функции и приглашения
- **Список друзей & Выбор контактов**: Поиск и добавление друзей по контактам / username (`c9d95599c1b14823a8dbebc0d20e9625`, `a84581550b954053a9ec1b70b6c00003`).
- **Пригласить по ссылке**: Генерация уникальной инвайт-ссылки / QR-кода для присоединения к группе (`30474e18ecf54481a6097e1f6c676f7d`).

### 3.6. Экспорт и отчеты
- **Экспорт в PDF/CSV**: Генерация детализированного отчета по группе со всеми транзакциями, чеками и финальным графом расчетов (`85d7db70ee2d4619bdebf5fa5233ca5d`).

## 4. Схема Базы Данных (Supabase PostgreSQL)
1. `profiles` (id, full_name, avatar_url, phone, email, telegram_id, default_currency, updated_at)
2. `groups` (id, name, category, default_currency, created_by, created_at)
3. `group_members` (group_id, user_id, role, joined_at)
4. `exchange_rates` (from_currency, to_currency, rate, updated_at)
5. `expenses` (id, group_id, paid_by_id, title, amount, currency, exchange_rate, amount_in_group_currency, category, split_type, receipt_url, ocr_data, created_at)
6. `expense_splits` (id, expense_id, user_id, amount_owed)
7. `settlements` (id, group_id, payer_id, payee_id, amount, currency, payment_method, proof_url, status, created_at)
8. `group_invites` (id, group_id, invite_code, expires_at, created_by)

## 5. Этапы реализации MVP
- **Этап 1**: Инициализация Next.js проекта, Tailwind, Shadcn UI и миграций Supabase.
- **Этап 2**: Авторизация (Email/Password, Magic Link, Telegram WebApp support), профили пользователей.
- **Этап 3**: Создание событий/групп, управление участниками и инвайт-ссылками.
- **Этап 4**: Модуль расходов (мультивалютность, конвертация, прикрепление чеков + OCR-распознавание, схемы сплита).
- **Этап 5**: Модуль баланса, алгоритм минимизации долгов (Debt Simplification), фиксация оплаты (Settle Up) и экспорт отчетов в PDF.
- **Этап 6**: Maker-Checker тестирование (Playwright, `npm run build`), рефакторинг UI под спецификации Stitch.
