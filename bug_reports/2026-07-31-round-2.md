## Как закрыты блокеры

**S0-1.** `signInUser` больше не игнорирует пароль. При настроенном Supabase
проверку делает `signInWithPassword`, ошибка возвращается вызывающему и
показывается пользователем. Без бэкенда работает локальный режим: пароль
хранится как соль + SHA-256 (`src/lib/credentials.ts`), неизвестный email
отклоняется, чужой email с неверным паролем отклоняется. Демо-вход остался
отдельной явной кнопкой — это единственный путь без проверки пароля.

Отдельно починен рендер: состояние `errorMessage` в `auth/page.tsx` существовало,
но нигде не выводилось, поэтому любая ошибка была невидимой.

**S0-2.** Идентификатор события уехал из пути в query-строку. Маршрутов теперь
фиксированное число, `generateStaticParams` не нужен вовсе:

```
/events/[id]                        ->  /events/detail?id=
/events/[id]/balance                ->  /events/balance?id=
/events/[id]/settle                 ->  /events/settle?id=
/events/[id]/export                 ->  /events/export?id=
/events/[id]/expense/new            ->  /events/expense/new?id=
/events/[id]/expense/[expenseId]/edit -> /events/expense/edit?id=&expenseId=
```

Ссылки собираются только через `src/lib/routes.ts`, чтобы следующий экран
нельзя было добавить мимо этого правила. Проверено вживую: URL
`/events/detail?id=group-1785451744682`, который в прошлом круге отдавал
`404.html`, теперь открывает событие.

## Новый дефект, найденный при живой проверке

### S1-3. Белый текст на белом фоне на шести экранах — **закрыт**

**Файл:** [src/app/globals.css:40](src/app/globals.css#L40)

`.stitch-card` объявлял `background: #ffffff`. Сокращение `background` сбрасывает
`background-image` в `none`, а Tailwind реализует `bg-gradient-*` именно через
`background-image`. Поэтому каждая карточка с классами
`stitch-card bg-gradient-to-br from-slate-900 ... text-white` теряла тёмный
градиент, оставалась белой, и белый текст на ней исчезал.

**Затронуто:** главная (две карточки), событие, баланс, друзья, профиль.
Пропадала в том числе сумма расходов события — главный показатель приложения.

**Почему не ловилось раньше:** текст физически присутствует в DOM. `innerText`
карточки возвращал `"ОБЩИЕ РАСХОДЫ СОБЫТИЯ\nАктивное 🟢\n9 000 ₽..."` — то есть
любая проверка по содержимому проходила. Не видят ни типы, ни `getByText`.

**Починка:** `background` → `background-color` (longhand не трогает
`background-image`). Одна строка.

**Регрессия:** `e2e/contrast.spec.ts` считает вычисленный контраст текста к
фактическому фону на пяти экранах. При возврате сломанного CSS падают все пять.

## Обратимость регрессий

Тест, который не падает на сломанном коде, бесполезен. Проверено обоими способами:

| Регрессия | Что временно ломали | Результат |
|---|---|---|
| `auth.spec.ts` | `signInUser` снова пускает неизвестный email | тест упал, после отката прошёл |
| `contrast.spec.ts` | `background: #ffffff` возвращён в `globals.css` | упали все 5, после отката прошли |
