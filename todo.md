## Блокирует бету

- [ ] **Прогон двумя аккаунтами на проде.** Единственная проверка, которая
  подтверждает GoTrue, PostgREST и Realtime под живой сессией. Сценарий — в
  конце `SUPABASE_SETUP.md`. Пока он не пройден, утверждать что
  многопользовательский режим работает, нельзя: проверены политики базы, но не
  HTTP-обвязка. *(🔍 CODEX в роли Чекера)*
- [ ] **Supabase → Authentication → URL Configuration.** Site URL и
  `https://split-it-ere9.vercel.app/auth` в Redirect URLs. Без этого письма со
  сбросом пароля ведут на localhost. *(🎨 Gemini или владелец)*
- [ ] **Решить про подтверждение email.** Если включено, а SMTP не настроен —
  тестировщики не войдут после регистрации. *(владелец)*

## Расчёты: написаны, но почти не проверены

Это главный технический долг. Код есть и работает на глаз, доказательств мало.

- [ ] **Алгоритм упрощения долгов** покрыт **одним** E2E-случаем: 9000 ₽ на
  троих сводится к двум переводам по 3000. Не покрыто: остаток от округления,
  встречные долги, частичные погашения, участник с нулевым балансом, группа из
  двух человек, длинная цепочка. Нужны unit-тесты на `simplifyDebts` — они
  дешёвые и быстрые. *(🧠 Claude Code)*
- [ ] **Конвертация валют не покрыта вовсе.** `convertCurrency` считает через
  рубль в два деления, ни одного теста. Отдельно: расход в валюте, отличной от
  валюты события, влияет на балансы всех участников. *(🧠 Claude Code)*
- [ ] **OCR не покрыт.** `extractDataFromText` разбирает чек регулярками, тестов
  нет. Достаточно нескольких фикстур с текстом настоящих чеков. *(🧠 Claude Code)*

## Закрыто в этом цикле

**Безопасность**

- [x] Клиентский Supabase Broadcast больше не передаёт local groups/friends;
  межвкладочный канал несёт только сигнал без пользовательского payload.
- [x] RLS переписан по deny-by-default: политика на операцию, `USING` +
  `WITH CHECK`, членство через `SECURITY DEFINER` функции.
- [x] Убраны пять политик `FOR ALL USING (true)`, открывавших финансовые таблицы.
- [x] `group_invites` и `exchange_rates` получили RLS — раньше его не было.
- [x] Вход по произвольному паролю закрыт.
- [x] Проверено на живой базе: анонимное чтение — пусто, запись — 401, функции
  доступны только `authenticated`.

**Целостность данных**

- [x] Приглашение по одноразовому коду, который расходуется через
  `DELETE ... RETURNING`.
- [x] Создание группы и правка расхода с долями — атомарные SQL-функции.
- [x] Отрицательные и нулевые суммы отклоняются разметкой, обработчиком и
  `CHECK` в базе.
- [x] Ссылка на чужое событие не подменяется выдуманной группой.

**Честность интерфейса**

- [x] Пустой список друзей не заполняется демо-контактами; отсутствующие
  phone/email и статус активности не выдумываются.
- [x] Удалена неработающая «персональная ссылка» `/auth?invite=friend`;
  настоящее приглашение создаётся только из карточки события.
- [x] Удалена симуляция OTA-обновления.
- [x] Видно, загружен курс валют или взят резервный.
- [x] Сбой OCR не выглядит как продолжающееся сканирование.
- [x] Белый текст на белых карточках на шести экранах.

**Инфраструктура**

- [x] `output: 'export'` и маршруты через query-строку: событие с любым id
  открывается в APK и на статик-хостинге.
- [x] Playwright по собранному `out/`, детерминированная сборка `build:test`.
- [x] Живая проверка RLS на PostgreSQL в WebAssembly, без Docker.
- [x] ESLint как настоящий gate.
- [x] Репозиторий: 17 638 файлов → 163, история очищена от 590 МБ артефактов.
- [x] Деплой на Vercel, публичный адрес определяется автоматически.
