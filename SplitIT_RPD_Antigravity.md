# RPD — Приложение для совместных трат

## Название
SplitMate (рабочее название)

## Цель
Создать кроссплатформенное мобильное приложение (iOS/Android) для учета совместных расходов с автоматическим расчетом долгов между участниками.

## Основные возможности

### Пользователи
- Регистрация: Email, Google, Apple ID
- Авторизация
- Профиль пользователя

### События
- Создание события
- Приглашение участников
- Архив событий

### Расходы
- Добавление расхода
- Фото чека
- Категории расходов
- Несколько способов распределения:
  - поровну
  - по долям
  - по фиксированным суммам

### Баланс
- Автоматический пересчет после каждого расхода
- Кто должен
- Кому должны
- Итоговые взаиморасчеты
